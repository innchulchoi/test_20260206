# 대한민국 기업집단 조직도 (공정위 명단 + DART 임원현황)

공정위가 매년 지정하는 기업집단 명단을 뼈대로 쓰고, 각 계열사의 DART 정기보고서에서 임원과 지분 정보를 모아
한 개의 HTML 파일을 만든다. 이 HTML에는 그룹 개요, 지배구조 트리, 회사별 임원 조직도가 들어간다.

## 구성

| 파일 | 역할 |
|---|---|
| `references/groups_2026.json` | 공정위 2026-05-01 지정 102개 집단: 순위, 동일인, 자산, 별칭, 계열사 3,538곳(법인등록번호, 금융 여부) |
| `references/name_overrides.json` | 글자 변환으로 맞출 수 없는 회사명 수동 매핑 (예: 네이버(주) → NAVER) |
| `references/dart_api.md` | 사용하는 DART API, 응답 필드, 상태코드, 호출량 계산. 오류가 나거나 필드를 추가할 때 읽는다 |
| `scripts/collect.py` | DART 수집. 결과는 그룹별 JSON (`data/001_삼성.json`), 모든 응답은 `data/cache/`에 캐시 |
| `scripts/report_doc.py` | 공시 원문(document.xml)에서 임원 표를 읽는다. API가 등기임원만 줄 때 미등기임원을 채운다 |
| `scripts/build_html.py` | 수집 결과를 단일 HTML로 렌더링 (`assets/orgchart_template.html` 사용) |
| `scripts/build_groups.py` | 새해 공정위 발표 엑셀(별첨2·별첨5)로 `groups_<연도>.json` 재생성 |

## 작업 순서

### 1. 범위와 키 확인

- 사용자가 원하는 범위를 정한다. 그룹 하나는 `--group 삼성`, 여러 그룹은 `--group 삼성,SK,LG`, 순위 범위는 `--rank 1-50`(기본값)으로 넘긴다.
  별칭(SK, LG, GS, CJ, 현대차 등)도 받는다. 공정위 공식 명칭은 "에스케이", "엘지"처럼 한글 표기라는 점에 유의한다.
- `DART_API_KEY` 환경변수가 있는지 확인한다. 키를 채팅에 붙여넣게 하지 말고, 환경변수나 환경 설정의 시크릿으로 등록하게 안내한다.
  키가 없으면 https://opendart.fss.or.kr 에서 무료로 발급받는다(인증키 신청 → 이메일 인증).
- `curl -s "https://opendart.fss.or.kr/api/list.json?crtfc_key=$DART_API_KEY" | head -c 200`로 연결과 키를 함께 확인한다.
  `"status":"013"` 또는 `"000"`이면 정상, `"010"`이면 키 오류, 연결 실패면 네트워크 허용 목록에 `opendart.fss.or.kr`이 필요하다.

### 2. 처음 한 그룹으로 시험

```bash
python scripts/collect.py --groups references/groups_2026.json --out data/ --group 삼성
python scripts/build_html.py --groups references/groups_2026.json --data data/ --out out/samsung.html --group 삼성
```

출력 한 줄에서 `DART 미등록` 수와 `임원현황 N개사`를 본다. 계열사 대부분은 정기보고서를 내지 않는 비상장사다.
그래서 임원현황이 나오는 회사는 보통 상장사와 채권 발행사뿐이고, 이것이 정상이다. 다만 **상장사인데 매칭이 안 됐다면**
(예: 영문 단어 상호) `references/name_overrides.json`에 `"공정위 회사명": "DART 회사명"`을 추가하고 다시 돌린다.
캐시가 있으므로 다시 실행해도 API를 거의 쓰지 않는다.

### 3. 전체 수집

```bash
python scripts/collect.py --groups references/groups_2026.json --out data/ --rank 1-50
python scripts/build_html.py --groups references/groups_2026.json --data data/ --out out/korea_top50_orgchart.html --rank 1-50
```

- 50개 그룹 전체는 약 2,000개 계열사를 확인하므로 API 4,000~6,000건을 쓴다. 일일 한도(20,000건) 안이고 10~20분쯤 걸린다.
  빨리 보고 싶으면 `--listed-only`로 상장사만 조회한다.
- 한도에 걸리거나 중간에 끊겨도 같은 명령을 다시 실행하면 캐시에서 이어간다.
- 삼성전자처럼 임원현황 API에 등기임원만 있는 회사는 보고서 원문을 받아 미등기임원 표를 읽는다(회사당 1건 추가).
  이렇게 채운 임원에는 `"source": "원문"`이 붙는다. 이 단계를 빼려면 `--no-document`를 준다.
- `--period annual`을 주면 직전 사업보고서 기준으로, 기본값 `latest`는 가장 최근 분기·반기 보고서 기준으로 모은다.

### 4. 결과 전달

HTML 하나에 데이터가 모두 들어 있어 그대로 열거나 공유할 수 있다. 전달할 때는 다음을 함께 알려준다.
- 기준 시점: 공정위 지정일(2026-05-01)과 회사별 보고서명. 보고서명은 페이지의 회사 헤더에 표시된다.
- 커버리지: 수집 그룹 수, 임원현황이 있는 회사 수, 총 임원 수.
- 주의점: 정기보고서 기준이라 그 뒤의 인사는 반영되지 않는다. "법인등록번호 불일치"나 "동명 법인 다수" 표시가 붙은 회사는 직접 확인이 필요하다.

## 페이지 구성 (build_html.py)

- **전체 개요**: 순위, 기업집단, 동일인, 지분 기준 최상위 회사(지주), 계열사 수, 공정자산, 공시 임원 수
- **그룹 › 지배구조**: 동일인을 뿌리로 두고, 각 계열사를 그룹 안에서 지분이 가장 큰 주주 밑에 둔 트리. 지분은 타법인출자현황과 최대주주현황에서 가져온다.
  상호출자로 생기는 순환은 끊는다. 지분 정보가 없는 계열사는 따로 모아 보여준다.
- **그룹 › 임원 조직도**: 회사별로 이사회(사내이사, 사외이사, 기타비상무이사, 감사)를 카드로 보여준다.
  미등기임원은 담당업무 문구("DS부문 메모리사업부 D램개발실장")를 부문 › 사업부 › 실 단위로 나눠 접히는 조직도로 만든다.
  이름을 누르면 생년월, 경력, 재직기간, 임기, 최대주주와의 관계를 볼 수 있다.
- **그룹 › 계열사 목록**: 공정위 명단 전체와 DART 매칭 상태
- 상단 검색: 임원 이름, 회사, 그룹을 모두 검색한다. URL 해시(`#g=1&t=org&c=...`)로 특정 화면을 링크할 수 있다.

담당업무를 조직 단위로 나누는 규칙은 `build_html.py`의 `unit_path()`에 있다. 특정 그룹의 표기 관행 때문에 묶음이 어색하면
이 함수를 고친다. 예를 들어 "부문"이 아니라 "Biz", "Division" 같은 영문 단위를 쓰는 회사는 `UNIT_SUFFIXES`에 추가한다.

## 새 연도 명단으로 갱신

공정위는 매년 5월 1일자로 "공시대상기업집단 지정 결과"를 발표한다(정책브리핑 korea.kr 보도자료 첨부 zip).
그 안의 `(별첨2) 지정현황.xlsx`와 `(별첨5) 계열회사 현황.xlsx`를 받아 다음을 실행한다.

```bash
python scripts/build_groups.py --designation 별첨2.xlsx --affiliates 별첨5.xlsx --year 2027 --out references/groups_2027.json
```

엑셀 양식이 바뀌면 `build_groups.py`의 열 위치를 맞춘다. 2026년 양식에서 별첨2는 B=순위, E=집단명, F=동일인, G=계열사 수, I=공정자산이고,
별첨5는 B=순위, F=비금융 회사명, H=금융 회사명, I=법인등록번호다.

## 판단이 필요한 부분

- **"50대 기업"의 기준**: 이 스킬은 공정위 공정자산총액 순위를 쓴다. 사용자가 매출 순위나 시가총액 순위를 원하면 그 점을 짚는다.
  공정위 순위에는 농협, 한국교직원공제회(74위)처럼 동일인이 법인인 집단과 쿠팡, 한국지엠 같은 집단도 들어 있다.
- **"조직도"의 범위**: DART에는 부서 단위 조직도가 없다. 공시된 것은 임원 명단과 담당업무다. 여기서 만드는 조직도는
  이 담당업무를 묶어 재구성한 것이므로, 사용자에게도 그렇게 설명한다.
- **개인정보**: 페이지에는 공시된 범위(이름, 생년월, 경력)만 담는다. 다른 출처에서 개인정보를 덧붙이지 않는다.
